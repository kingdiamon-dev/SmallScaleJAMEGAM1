Welcome to SMALL SCALE

You can play the game here: https://santihehe.itch.io/small-scale

Build with Godot Engine, all code and assets are original

This repo contains the project

--DESCRIPTION--

Small Scale is a game where you are... well, small. You must traverse the large land, searching for your tribes arch 
enemy- the evil cat, Calicus the Terrible. You fight the evil cat lord's minions, finally making it to the end.

--CONTROLS--

Arrow Keys to move

Z to jump

X to run 

Down arrow while in air to ground pound

--DISCLAIMER--

Currently, this game is not complete. Only a tutorial level is included. More coming soon!
